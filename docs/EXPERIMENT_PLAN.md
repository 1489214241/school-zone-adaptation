# 按区调整与按区均衡训练：一轮试验（2026-11-10，开跑前冻结）

## 要回答的问题
在现有完整模型（代码库 `configs/default.json`，pre_v1 数据）上，加两样少样本方向的公认技术，模型部分准确率有没有可确认的提升：
- **B 按区均衡训练**（任务均衡采样的全批量版本）：现在每个楼盘组等权，长沙的训练题约占三分之二。
- **A 按区概况调节证据权重**（任务条件化，TADAM / CNAPs 一类）：现在所有区共用一套网络权重（只有线性起点按本区拟合）。

只做这一轮；不调超参数；两样分开测。

## 各臂（都只改训练/模型开关，输入证据、规则结果、核验参照、评价小区与基线完全相同）
| 臂 | 设置 | 说明 |
|---|---|---|
| BASE | 不改 | 重跑一遍，必须与 pre_v1 已有结果一致（自检） |
| **B1（主）** | `train.balance = "district"` | 每个区的训练题总权重相等（区内仍按楼盘组等权） |
| B2（对照） | `train.balance = "city"` | 两座城市总权重相等（城内按楼盘组等权） |
| AS（对照） | `model.condition = true` | 区概况 z 固定（用全部已知小区算），调节证据块增益 |
| A0（对照） | `train.reference_dropout = 0.8` | 每步每区随机藏掉一部分参照楼盘（比例 ρ~U(0,0.8)），不调节 |
| **A1（主）** | A0 ＋ `model.condition = true` | 每步按藏掉后剩下的已知小区重算 z，再调节 |

区概况 z（7 个数，只用该区的已知小区〔规则判出＋核验参照〕和政策证据，不用官方答案；各减 0.5）：
1. 有参照的学校占比；2. 是参照的楼盘组占全区楼盘组的比例；
3. 已知小区之间"抄最近的别组参照"的一致率（不足 5 个记 0.5）；
4. 其中最近参照隔主干/次干/铁路河流时的一致率；5. 不隔时的一致率（不足 5 个时都取第 3 项）；
6. 政策里有四至状态的学校占比；7. 名字与某校政策名单部分对上的小区占比。

调节方式：每个证据块一个增益 g = 1 + U·z（参照一路 9 块＋参照所属学校证据＋周边统计；学校一路 5 块＋周边统计），学校一路偏置加 u·z；
U、u 从 0 起步（起点与基线完全相同），正则系数与网络相同；优化器、步数（40）、学习率、10 个种子都不变。预测时不藏参照，z 用全部已知小区算。

## 评价
- 数据：pre_v1（杭州答案未冻结）。K=0（第 1 批）与 K=1（第 1、2、3 批核验对象）。
- 指标：臂 − 基线，两城，模型部分（规则与核验都没判出、有官方答案的小区）；区间：按区分层、1 公里空间块 bootstrap 3000 次；另报改对/改坏、长沙、杭州。

## 事先判定（每臂、每个 K 分开）
- K=0：区间下界 > 0 → 过；跨零 → 未确认；上界 < 0 → 有害。
- K=1：三批下界都 > 0 → 过；部分 > 0 → 不稳；都跨零 → 未确认；三批上界都 < 0 → 有害。
- **并入模型的条件**（只对主臂 B1、A1）：K=1 判"过"，且 K=0 不是"有害"，且长沙、杭州任一城在任一批都没有区间上界 < 0。
- 对照臂（B2、AS、A0）只用来解释主臂，不单独并入。五臂没有做多重比较校正，对照臂的结果只作描述。
- 两个主臂都满足并入条件时，追加一次 B1＋A1 合并（描述性，不改上面的判定）。
- 都不满足：不并入；写进消融表（"按区均衡 / 按区调节：未带来可确认提升"）。

## 自检
- BASE 臂与 `outputs/main_pre_v1/k<K>_s<seed>/probs` 的概率最大差 < 1e-5，判对小区逐个相同。
- `scripts/verify.py train` 仍逐位一致（默认路径没动）。
- 条件化臂在 U=0 时输出与基线相同（起点检查）。
